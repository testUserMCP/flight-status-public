# flight-status-public

This project snapshot is included in the repository so visitors can inspect the code in-place.

## What it does

A tiny command-line tool that prints flight status from a bundled timetable.

## Usage

```bash
python flight_status.py LH400
```

Example output:

```text
Flight LH400: On time
```

## Files

- `flight_status.py` — command-line entry point
- `timetable.json` — example timetable used by the tool
